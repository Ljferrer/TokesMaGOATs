Method and sources

Energy = (fresh input × fresh rate + cached input × cache rate + output × output rate) ÷ 1,000,000. Cache creation is fresh input; reasoning is counted once within output. CO₂ = facility kWh × assumed grid kg CO₂/kWh ÷ 1,000. Flight equivalents = metric tons CO₂ ÷ 0.27, a generic long-haul economy proxy for LAX–JFK excluding non-CO₂ aviation effects.

Low/high are sensitivity scenarios, not confidence bounds. Open-model measurements motivate the scale but do not measure these proprietary models. The cached-energy ratios are assumptions, not API price discounts. Full derivation and model comparisons are in CARBON_METHODOLOGY.md.
