# Repository instructions

Store audit traces (Snipe panels, repair logs, and validation or mutation evidence) in [Ljferrer/DocTrail](https://github.com/Ljferrer/DocTrail), checked out locally at `~/GitHub/DocTrail`, under `TokesMaGOATs/audits/YYYY-MM-DD-<episode>/`. Read DocTrail's `CONTEXT.md` for bundle, provenance, and byte-preservation rules. Do not commit these traces to this repository; link PRs to their DocTrail bundles. Keep live product documentation with the application.
